# Go REST API

Go HTTP server with REST API and web interface.

## Features
- Go HTTP server
- REST API endpoints
- Interactive web UI
- Graceful shutdown

## Quick Start
```bash
docker build -t go-rest-api .
docker run -p 8080:8080 go-rest-api
```

Visit: http://localhost:8080
