# PHP Web App

PHP web application with system dashboard and modern UI.

## Features
- PHP backend
- System information dashboard
- Session management
- Database ready

## Quick Start
```bash
docker build -t php-web-app .
docker run -p 8080:80 php-web-app
```

Visit: http://localhost:8080
